# Impulse — Marketing Assets

Repositório público de **materiais aprovados para divulgação** da Impulse.

## Organização

- `brand/logos/` — arquivos de logomarca oficiais, sem recriação ou alteração por IA.
- `posts/2026/11/` — imagens finais aprovadas, organizadas por ano e mês.
- `videos/` — vídeos finais aprovados.
- `metadata/` — legendas, textos alternativos, canais e situação de publicação.

## Critérios obrigatórios

1. Aplicar a skill editorial **impulse-social-media** e a identidade visual atual do site.
2. Inserir a logo como arquivo original (nunca pedir que IA a desenhe ou reinterprete).
3. Publicar neste repositório **somente conteúdo aprovado para divulgação**. Rascunhos e materiais internos não devem ser enviados a um repositório público.
4. Não publicar dados de clientes, código proprietário, tokens, credenciais ou informações confidenciais.
5. Publicação e agendamento em redes sociais dependem de autorização e confirmação do serviço publicador; um arquivo salvo no GitHub **não significa que foi publicado**.

## Integração com os canais

Para uma imagem já aprovada, usar uma URL HTTPS do arquivo fixada em commit, por exemplo:

`https://raw.githubusercontent.com/ivanramosdossantos/impulse-marketing-assets/<COMMIT_SHA>/posts/2026/11/<ARQUIVO>.png`

Verificar se o publicador consegue baixar a mídia antes de agendar Instagram e LinkedIn.
